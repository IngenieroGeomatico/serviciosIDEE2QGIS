# serviciosIDEE2QGIS

Este complemento permite añadir de forma rápida y sencilla servicios web (WMS, WMTS, WFS, etc.) de la Infraestructura de Datos Espaciales de España (IDEE) directamente en QGIS. Facilita el acceso a datos geográficos oficiales del IGN-CNIG y otras instituciones públicas.

Con este plugin podrás explorar, filtrar y cargar servicios de la IDEE sin necesidad de introducir manualmente las URL. Ideal para usuarios que trabajan con cartografía oficial, geoinformación pública o proyectos de la administración.
